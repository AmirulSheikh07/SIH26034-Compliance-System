# SIH26034 - Legal Metrology Compliance System

AI-based software system for checking compliance of packaged commodities under the Legal Metrology (Packaged Commodities) Rules, 2011.

## Team Modules

- Member 1 - OCR + AI/Vision + Image Processing
- Member 2 - Legal Metrology Rule Engine + Compliance Validation
- Member 3 - Backend + Database + APIs
- Member 4 - Frontend + Dashboard + Reports
